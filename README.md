1. Create React vite app.
        command->
                npm create vite@latest e-commerce-frontend
        
        command to run ->
                npm run dev
        
2. Installing React strap in our project to use built-in components in website.
        command->
                npm install reactstrap
        command for bootstrap ->
                npm install bootstrap
        CDN ->
                import 'bootstrap/dist/css/bootstrap.min.css';
                add this in main.jsx

3. Installing React Router in our project to manage routes.
        command->
                npm install react-router

4. Installing Axios for backend calling and fetching data from backend and database.
        command->
                npm install axios

5. Installing React Icon Package for icons ->
        command->
                npm install react-icons
6. Installing React hot toast for showing toast messages
        command->
                npm install react-hot-toast

7. Installing stripe and react stripe
        command->
                npm install @stripe/stripe-js @stripe/react-stripe-js
